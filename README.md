# Finances & Investments

A private personal money app for Ziad. Four tabs: Overview, Money, Investing, Plan.
All data is stored on your own phone (nothing is sent anywhere). Use the in-app
**Back up** button to save a copy of your numbers, and **Restore** to load one back.

## Files
- `index.html` — the whole app
- `months.json` — the monthly investment buy lists shown on the Investing tab
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — let it install to the home screen and work offline
- `netlify.toml` — hosting config

## Hosting
Published free on Netlify from this repository. Every push updates the live app.
